# SafeRoute AI 최종 녹화 시나리오

## 문서 상태

- 상태: Approved
- 담당: 팀 안전빵
- 최종 갱신: 2026-08-13
- 적용 대상: 현재 관리자 관제 화면, 상황 예측 화면, 기사 앱
- 목표 길이: 앱 조작 약 3분 + Remotion 엔딩

## 1. 녹화 기준

- 데모 데이터는 실제 기사가 아닌 합성 기사 25명임을 첫 장면에서 밝힌다.
- 상황 예측은 현재 관제 계획을 즉시 변경하는 기능이 아니라, 선택한 날짜·시간과 조정 조건으로 결과를 미리 보는 별도 시뮬레이션이다.
- 본 시연의 지원 대상은 `문상혁 기사`, 선택 개입은 `배송 4건 분담`, 분담 기사는 `안재민 기사`로 진행한다.
- `15분 휴식`과 `배송 4건 분담`은 서로 다른 선택지다. 두 조치를 결합한 계획처럼 설명하지 않는다.
- Safety 수치와 추천은 결정론 엔진의 결과이며, AI가 계산하거나 추천을 변경한다고 설명하지 않는다.
- 화면에서 시간이나 Safety 수치가 달라지면 녹화 화면에 표시된 값을 그대로 읽는다. 임의로 숫자를 덧붙이지 않는다.

## 2. 녹화 전 준비

1. 브라우저 배율을 100%로 맞추고 관리자 관제 첫 화면을 연다.
2. 기사 이동이 도로를 따라 보이도록 지도를 한 단계 와이드 아웃한다.
3. 화면 하단 기사 목록에서 `문상혁 기사`가 보이는지 확인한다.
4. 지원 검토에서 `배송 4건 분담 · 안재민 기사`가 표시되는지 확인한다.
5. 이전 동의·승인 상태가 남아 있으면 데모 상태를 초기화한 뒤 녹화를 시작한다.
6. 알림, 주소창 자동완성, 개발자 도구는 모두 닫는다.

## 3. 최종 진행 순서와 멘트

진행 순서는 `1 → 3 → 4 → 5 → 6 → 7 → 8 → 9 → 10 → 2 → Remotion 엔딩`으로 고정한다.

### 1번. 문제 제시와 실시간 관제 소개 — 0:00~0:20

**화면·조작**

- 관리자 관제 첫 화면을 전체로 보여준다.
- 지도 위 기사들의 도로 기반 이동과 하단의 기사 현황을 2~3초간 보여준다.

**최종 멘트**

> 기존 배송 시스템은 더 빠른 길을 찾습니다. SafeRoute는 그보다 먼저, 현재 계획을 계속 수행해도 안전한지를 확인합니다. 합성 기사 25명이 실시간으로 배송을 진행하고 있습니다.

**화면에서 남길 증거**

- 합성 기사 25명
- 실제 도로를 따라 움직이는 기사 위치
- 향후 지원이 필요한 기사 수

### 3번. 지원이 필요한 기사 선택 — 0:20~0:36

**화면·조작**

- 관리자 관제 화면으로 돌아온다.
- 기사 현황에서 `문상혁 기사`를 선택한다.
- 화면에 표시된 예상 지원 시점과 배송 순서를 가리킨다.

**최종 멘트**

> 관제 화면에서는 향후 60분 안에 지원이 필요한 기사를 먼저 확인할 수 있습니다. 현재 점수만 보여주는 것이 아니라, 몇 분 뒤 몇 번째 배송지 전에 안전 기준에 닿는지를 예측합니다.

**화면에서 남길 증거**

- 문상혁 기사 선택 상태
- 예상 지원 시점
- 안전 기준에 닿기 전의 배송 순서

### 4번. 안전한 지원안 비교 — 0:36~0:54

**화면·조작**

- `지원 검토`를 누른다.
- 휴식, 순서 변경, 안전 경로, 시간 재약정, 배송 분담 후보를 천천히 훑는다.
- 실행 가능한 후보와 차단된 후보의 사유가 함께 보이게 한다.

**최종 멘트**

> 지원 검토에서는 휴식, 순서 변경, 안전 경로, 시간 재약정과 배송 분담을 같은 안전 기준으로 비교합니다. 안전 기준을 통과하지 못한 선택지는 빠르거나 편리하더라도 실제 후보에서 제외합니다.

**화면에서 남길 증거**

- 여러 지원안의 전후 결과
- `가능` 또는 `차단` 상태
- 차단된 이유

### 5번. 배송 4건 분담과 위험전가 방지 — 0:54~1:16

**화면·조작**

- `배송 4건 분담`을 선택한다.
- 우측에서 분담 기사가 `안재민 기사`임을 보여준다.
- 안재민 기사의 분담 후 Safety Budget과 기준 45 통과 상태를 가리킨다.

**최종 멘트**

> 여기서는 배송 4건 분담을 선택합니다. SafeRoute는 물량을 넘겨받는 안재민 기사의 예상 안전여유도 함께 계산하고, 기준 45를 지킬 때만 분담을 허용합니다. 한 기사의 위험을 다른 기사에게 넘기지 않기 위한 안전장치입니다.

**화면에서 남길 증거**

- 배송 4건 분담
- 안재민 기사 이름
- 분담 후 Safety Budget과 기준 45 통과

### 6번. 결정론 엔진과 AI의 역할 — 1:16~1:33

**화면·조작**

- `AI 근거 설명`을 펼친다.
- 수치와 추천 결과, AI 설명이 구분되어 보이게 잠시 멈춘다.

**최종 멘트**

> Safety 수치와 추천은 결정론 엔진이 계산합니다. AI는 검증된 운영 근거를 바탕으로 관리자와 기사에게 판단 이유를 설명합니다. AI 응답이 달라지거나 실패해도 안전 기준과 추천 결과는 바뀌지 않습니다.

**화면에서 남길 증거**

- 결정론적으로 계산된 수치와 추천
- 별도로 표시된 AI 설명
- 동일한 안전 기준

### 7번. 지원받는 기사 확인과 동의 — 1:33~1:50

**화면·조작**

- 관리자 화면에서 `기사 확인 요청`을 누른다.
- `기사 앱`으로 이동해 문상혁 기사의 `안전지원` 화면을 연다.
- 조정 내용과 `동의`, `수정 요청`, `지금은 거절` 선택지를 보여준 뒤 동의를 누른다.

**최종 멘트**

> 계획은 자동으로 바뀌지 않습니다. 먼저 문상혁 기사가 분담될 배송과 자신의 변경 결과를 확인합니다. 동의, 수정 요청과 지금은 거절은 불이익 없는 동등한 선택입니다.

**화면에서 남길 증거**

- 관리자와 같은 조정 내용
- 동의·수정 요청·거절 선택지
- 문상혁 기사 동의 완료

### 8번. 분담 기사의 확인과 동의 — 1:50~2:07

**화면·조작**

- 기사 선택을 `안재민 기사`로 바꾼다.
- `안전지원` 화면에서 추가되는 배송 4건과 분담 후 안전여유를 보여준다.
- 안재민 기사의 동의를 누른다.

**최종 멘트**

> 배송을 나눠 맡는 안재민 기사도 추가되는 배송 4건과 자신의 분담 후 안전여유를 확인한 뒤 동의합니다. 두 기사 모두 동의해야 관리자 승인 단계로 넘어갑니다.

**화면에서 남길 증거**

- 안재민 기사 이름
- 추가 배송 4건
- 분담 후 기준 통과와 동의 완료

### 9번. 관리자 최종 승인 — 2:07~2:25

**화면·조작**

- 관리자 관제 화면으로 돌아온다.
- 두 기사 동의 완료와 최신 안전검사 결과를 확인한다.
- `승인 및 계획 적용`을 누른다.

**최종 멘트**

> 관리자는 두 기사 동의와 최신 안전검사 결과를 다시 확인한 뒤 최종 승인합니다. 기사 동의와 관리자 승인이 모두 끝나기 전에는 기존 배송계획이 유지됩니다.

**화면에서 남길 증거**

- 두 기사 동의 완료
- 최신 안전검사 통과
- 관리자 승인

### 10번. 계획 갱신 확인 — 2:25~2:40

**화면·조작**

- 적용 완료 화면에서 변경된 계획과 상태를 보여준다.
- 지도 또는 완료 요약을 2~3초 유지한다.

**최종 멘트**

> 승인이 끝나면 경로, 배송 순서, 예상 도착시각과 고객 안내 상태가 같은 결정 ID로 함께 갱신됩니다.

**화면에서 남길 증거**

- 계획 적용 완료
- 경로·배송 순서·ETA·고객 안내 상태 갱신
- 동일한 결정 ID

### 2번. 별도 상황 예측 — 2:40~3:02

**화면·조작**

- 상단의 `상황 예측`을 누른다.
- 날짜와 시간을 선택한다.
- `업무량`과 `현재 안전여유`만 조정한다.
- `이 조건으로 다시 예측`을 눌러 예상 결과가 바뀌는 모습을 보여준다.

**최종 멘트**

> 마지막으로 관리자는 별도의 상황 예측 화면에서 날짜와 시간을 선택하고, 업무량과 현재 안전여유만 조정해 예상 안전여유와 지원 시점을 미리 확인할 수 있습니다. 이 결과는 현재 운영계획을 바로 바꾸지 않는 별도의 사전 시뮬레이션입니다.

**화면에서 남길 증거**

- 선택한 날짜와 시간
- 업무량과 현재 안전여유 조정값
- 예상 안전여유와 지원 시점의 변화

### Remotion 엔딩 — 상황 예측 다음

**화면·편집**

- 상황 예측 화면이 끝난 뒤 Remotion 엔드 카드로 전환한다.
- SafeRoute 로고와 핵심 문장을 표시한다.

**최종 멘트**

> 더 빠른 길보다 먼저, 끝까지 안전한 계획. SafeRoute AI입니다.

## 5. 녹화 중 주의할 표현

- `실제 기사`가 아니라 `합성 기사`라고 말한다.
- `사고 확률`이나 `사고를 줄였다`고 말하지 않는다.
- 상황 예측 결과가 현재 관제에 자동 적용된다고 말하지 않는다.
- `AI가 안전점수를 계산한다`거나 `AI가 최종 결정한다`고 말하지 않는다.
- 배송 4건 분담과 15분 휴식을 하나의 결합 개입처럼 말하지 않는다.
- 기사 동의 전에 계획이 적용된다고 말하지 않는다.
