# SafeRoute AI 데이터 출처 등록부

## 문서 상태

- 상태: Draft
- 담당: 팀 안전빵
- 최종 갱신: 2026-08-06
- 승인 조건: 공급자 이용신청·표본 응답·라이선스·필드 매핑·원본 hash 검증
- 상위 결정: ADR-022

## 1. 목적

이 문서는 SafeRoute가 실제로 수집한 데이터와 조사만 한 후보를 분리하고, `PUBLIC_DATA_DERIVED` 또는 `LIVE` provenance를 부여하기 전에 필요한 증거를 관리한다. 후보 목록에 있다는 사실은 수집·사용·학습 승인을 뜻하지 않는다.

## 3. 후보 승인안

### DS-001 — 기상청 단기예보 조회서비스

- 상태: API허브 4.1·4.2 활용 승인·키 발급, 계약 어댑터·Mock·비식별 Live 단일 표본 검증 완료
- 공식 출처: https://apihub.kma.go.kr/apiList.do?seqApi=10&seqApiSub=286
- API: `4.1 초단기실황조회`, `4.2 초단기예보조회`
- 제공기관: 기상청
- 형식·주기: REST, JSON·XML, 실시간
- 확인된 범위: 초단기실황, 초단기예보, 단기예보, 전국 5km 격자
- SafeRoute 허용 필드: 발표시각, 격자, 강수, 기온, 풍속과 원본이 제공하는 관측·예보 구분
- 허용 용도: Live/Mock/Error/Fallback 어댑터 검증과 완전한 도메인 입력을 만들기 전의 부분 후보
- 금지 용도: 사고확률, 기사 건강상태, 도로 결빙·시정 등 원본에 없는 값의 임의 추론
- 이용조건 메모: 공공저작물 출처표시 제1유형과 제3자 권리 표시 확인 필요
- 구현 증거: API허브 두 HTTPS endpoint exact allowlist, `authKey` 서버 분리, 응답 body SHA-256, 실황 최신성·예보 최대 6시간·크기·스키마·provider 오류 검증, 정상·결측·오래됨·혼합 격자·중복·범위·인증·rate limit·timeout 테스트
- Live 증거: 2026-07-17 실황 1시점·예보 6시점 통과. `RN1`의 정확값과 `1mm 미만`·`30~50mm`·`50mm 이상` 구간을 임의 중간값 없이 분리하며 인증키·원문 응답은 저장하지 않는다.
- 현재 차단: 초단기실황과 초단기예보에도 `WeatherState` 필수 필드인 체감온도·시정·노면상태·시간당 적설이 모두 직접 제공되지는 않는다. `safeForSafetyEngine=false`이며 보완 출처·변환 정책 승인 전에는 Demo/Fallback 날씨를 사용한다.
- 반복 Live 전 조건: 호출 빈도·보존기간 승인과 격자 매핑 버전 기록. 현재 단일 표본을 실제 운영 품질이나 Safety 효과로 확대 주장하지 않는다.

### DS-002 — 서울특별시 실시간 도로 소통 정보

- 상태: P0 조건부 후보
- 공식 출처: https://www.data.go.kr/data/15058364/openapi.do
- 데이터 ID: `15058364`, 원본 시스템 서울 TOPIS
- 형식·주기: JSON·XML, 실시간
- 확인된 필드: 링크 ID, 속도, 여행시간
- 허용 용도: 서울 Demo 권역의 ETA·혼잡 보조 입력
- 금지 용도: 경사, 도로폭, 주차난도, 사고위험이나 기사 위험점수의 대체값
- 이용조건 메모: 이용허락범위 제한 없음으로 표시되나 서울 열린데이터광장 인증키·호출정책을 별도 확인
- 수집 전 조건: 링크 ID와 합성 경로의 매핑을 Demo 전용으로 격리하고 실제 주소·기사 궤적을 저장하지 않음

### DS-003 — TAAS 교통사고정보 OpenAPI

- 상태: 화물차 다발지역·지자체 통계 REST JSON 활용 승인, 계약 어댑터·Mock 완료, Live 부분 검증
- 공식 출처: https://taas.koroad.or.kr/web/shp/adi/initOpenApi.do?menuId=WEB_KMP_TAI_TOS
- 제공기관: 한국도로교통공단
- 승인 API: `화물차 교통사고 다발지역 정보 API`, `지자체별 대상 교통사고 통계 API`
- 형식: HTTPS REST·JSON. WMS·PNG는 사용하지 않는다.
- 확인된 범위: 화물차 다발지역의 발생·사상자 집계와 공개 중심점, 지자체별 사고유형 통계
- 허용 용도: 지역 운영 맥락, 지도 설명, 평가셋 층화와 실제 공공데이터 사용 근거
- 금지 용도: 개인 기사 사고확률, 징계·순위, 단일 사고지점의 직접 경로 차단, 인과효과 주장
- 이용조건 메모: 활용 시 TAAS 출처와 자료 링크 명시. 인증키·원문 응답은 산출물에 저장하지 않는다.
- 구현 경계: 한 포털 키의 API별 승인 또는 API별 별도 키, exact HTTPS endpoint, 응답 크기·timeout·provider code·스키마·geometry·사상자 합계 검증, `NODATA_ERROR`의 정상 무자료 상태, SHA-256 provenance를 사용한다.
- 2026-07-24 Live 확인: 기존 포털 키에 두 API 권한을 등록한 뒤 화물차 영등포구 2024년 3개 지점과 지자체 통계 중랑구 2024년 13개 사고유형을 함께 검증했다. 최초 통계 미등록 응답과 수정 후 완료 run을 모두 보존한다.
- Safety 경계: 두 결과 모두 `safeForSafetyEngine=false`이며 현재 Safety Budget·Time-to-Breach·추천·Risk Transfer Guard에 입력하지 않는다. 실제 지역 통계와 합성 기사·배송계획이 함께 있으면 전체 장면은 계속 Demo다.
- 남은 조건: 표시 공간 단위·최소 표본·시간감쇠 정책 승인

### DS-004 — AI Hub 국도 CCTV 영상을 통한 비정상 주행 판별 데이터

- 상태: P2 보류
- 공식 출처: https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=71566
- 확인된 규모: 국도 CCTV 기반 이미지·JSON 약 211만 건, 정상·비정상 주행 분류
- 보류 이유: 라스트마일 배송기사의 골목·계단·작업량 P0와 직접 일치하지 않고 저장공간·다운로드·영상 개인정보·학습 비용을 크게 늘린다.
- 재검토 조건: P0 폐루프 완료, 좁은 도로환경 파생 특징의 명시적 수용기준, 이용조건·비식별 처리 검토, 작은 표본 기준선과 독립 검증셋 확보
- 금지 용도: 데이터를 받았다는 이유만으로 A100 학습을 수행하거나 실제 배송 위험모델이라고 주장

### DS-005 — 기상청 고해상도 격자자료 특정지점 다중요소

- 상태: 활용 승인·Live 단일 표본·계약 검증 완료, Safety 부분 후보
- 공식 출처: https://apihub.kma.go.kr/apiList.do?seqApi=971
- 후보 API: `1.3 특정지점 다중요소 API`
- 확인된 범위: 500m 분석격자, 5분 생산, `ta_chi` 체감온도·`vs` 시정·`sd_3hr` 3시간 신적설 등
- 검증 결과: 공식 공개 예시 대표점의 2026-07-17 21:30 KST 응답에서 `ta_chi=29.7°C`, `vs=7.0km`를 검증하고 시정은 7,000m로 단위 변환했다. `sd_3hr=0cm`는 원래 의미인 3시간 신적설로만 보존했다. 같은 관측시각의 시정이 최초 6.9km에서 7.0km로 공급자 측 갱신되어 최신 응답 SHA-256 `9a72ad20d9b2fdcd2b11cfd48e1eeaadb633e32f148e102d58872cc865af9ef0`로 교체됐으며 이전 불변 실행도 보존했다. 응답 원문·위경도·인증키는 저장하지 않았다.
- 허용 용도: 현재 시점의 체감온도·시정 후보와 3시간 신적설 참고값
- 한계: 관측자료에 지형효과를 반영한 분석값이며 실제 관측과 차이가 있을 수 있다. `sd_3hr`를 시간당 적설로 나누거나 미래값으로 복제하지 않는다. 특정지점 위경도는 Demo 권역의 비식별 대표점만 사용한다.
- 남은 조건: 실제 운영 권역 대표점 승인, 계절별 결측 반복 표본, 미래 120분 처리 정책. 현재값을 예보로 복제하지 않는다.

### DS-006 — 기상청 동네예보 4.3 단기예보

- 상태: 활용 승인·Live 단일 응답·120분 적설 계약 검증 완료, Safety 부분 후보
- 공식 출처: https://apihub.kma.go.kr/apiList.do?seqApi=10&seqApiSub=286
- 후보 API: `4.3 단기예보조회`
- 확인된 범위: 시간별 예보와 `SNO` 신적설 후보
- 검증 결과: 2026-07-17 20:00 KST 발표에서 최신 실행의 22·23·00시 `SNO` 3개 시점을 검증했으며 모두 정확값 0cm/h였다. 같은 시점의 `TMP·REH·WSD`에서 공식 여름식을 적용한 체감온도는 각각 약 30.04·29.38·28.71°C였다. 응답 원문·인증키는 저장하지 않고 SHA-256 `0704cc984d963681daa0a38d8be091b196cca0b267429b1f2855453ffe3d2a31`만 보존했다.
- 허용 용도: 120분 Safety horizon의 미래 시간당 신적설 후보. `0.5cm 미만`과 `5.0cm 이상`은 중간값 없이 구간으로 보존한다. 같은 시점의 `TMP`·`REH`·`WSD`는 기상청 공식 계절별 체감온도식의 입력으로만 허용한다.
- 한계: 발표주기·발효시각 정렬과 `SNO` 정성 구간을 별도 검증해야 하며, 4.2보다 오래된 발표를 최신값처럼 표시하지 않는다.
- 남은 조건: 적설 발생 시의 구간형 Live 반복 표본과 계절 경계 검증

## 4. 등록 절차

1. 공식 데이터 ID·URI·버전·이용조건을 승인한다.
2. 개인·차량·정밀 위치 정보와 재식별 위험을 점검한다.
3. 최소 표본만 격리 폴더에 수집한다.
4. 원본 bytes의 SHA-256과 수집시각을 manifest에 기록한다.
5. 허용 필드와 단위·결측·시간대·공간 정밀도 매핑을 승인한다.
6. 결정론적 변환기와 계약 테스트를 작성한다.
7. 원본과 변환 결과를 함께 검증한 뒤에만 `PUBLIC_DATA_DERIVED`를 부여한다.
8. Live 장애·오래된 값·빈 응답·Fallback을 검증한다.

## 5. 수용기준

- 데이터마다 공식 ID·URI·버전·라이선스·원본 hash·변환기 버전이 있다.
- 원본에 없는 안전 특징을 생성하지 않는다.
- 공공 집계와 실제 배송 운영 데이터, Demo fixture를 혼합 표시하지 않는다.
- 실제 개인정보와 정밀 기사 궤적을 평가 fixture·로그·스크린샷에 넣지 않는다.
- 학습 사용은 별도 데이터셋 카드, 분할, 기준선과 승인된 목적이 있을 때만 허용한다.

## 6. 비목표

- 승인 범위를 넘어 후보 데이터를 즉시 대량 다운로드하거나 API 키를 저장소에 넣는 것
- 공공 통계를 사고확률 또는 기사평가 라벨로 사용하는 것
- P0와 무관한 대규모 영상 학습으로 A100 사용량을 늘리는 것
- 수집 전 데이터의 품질·대표성·효과를 성공으로 주장하는 것

## 7. 미결사항

- 현재 시간당 적설의 직접 관측 계약 또는 보수적 대체 정책
- 미래 120분 육상 시정의 승인된 직접 출처와 반복 표본 보존 범위
- DS-005·DS-006의 계절·강설·저시정 조건 반복 Live 검증
- 서울 TOPIS 링크 ID와 Demo 경로의 비식별 매핑 방식
- TAAS 공간 집계 정밀도·최소 표본·시간감쇠 기준
- AI Hub 이용조건과 멀티모달 P2 재검토 시점
- 실제 TMS·배송 운영 데이터의 법적 근거와 보존기간
