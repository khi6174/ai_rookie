# SafeRoute AI Scenario-driven Service

- 상태: Approved
- 담당: 팀 안전빵
- 최종 갱신: 2026-08-10
- 적용 범위: 외부 연동 직전 사용자 입력 운영상황 예측

## 1. 목표

고정된 Demo 장면을 재생하는 대신, 사용자가 가상의 배송 운영조건을 입력하면 현재 결정론적 Safety 엔진과 개입 엔진이 계획 전체를 다시 계산하도록 한다. 실제 외부 연결 전에도 입력 변화에 대한 일반성, 안전 하드 제약과 실행 가능한 대응을 직접 시연한다.

## 2. 완료 기준

- 관측 기반 기본 입력과 선택적인 가상 기상 입력이 strict 계약을 통과한다.
- 입력 화면은 `1-1 관측 시점 선택`과 `1-2 시뮬레이션 조건 설정`을 서로 다른 영역으로 구분하고 하나의 최종 예측으로 합친다.
- 최근 31일 날짜와 시간을 달력에서 선택하고 ASOS Live·활용신청 대기·오류를 구분한다.
- 날짜·시간 선택은 업무·안전여유 기준 상황을 바꾸지 않는다.
- 날짜·시간을 선택하면 기준 상황은 유지한 채 관측 강수·시정을 1-2에 즉시 설정하고, 예상 최저·안전한계 시점·추천의 적용 전후를 다시 계산한다. 별도 적용 버튼은 두지 않는다.
- 기본 상태는 `ASOS 관측 기반`으로 표시하고 복합 상황 프리셋을 노출하지 않는다. 사용자가 `가상 기상 스트레스 테스트`를 켠 경우에만 강수·체감온도·시정 slider를 노출하고 `사용자 가상 기상`으로 구분한다.
- 연속작업·두 기사 안전여유·숙련도·기상·경로 조건은 상태어와 정확값을 함께 제공하는 키보드 조작 슬라이더다.
- Safety Budget, Time-to-Breach, 예상 배송지·신뢰도·기여요인이 입력마다 재계산된다.
- 휴식·물량분담·묶음·안전경로·Safe Delay 후보를 비교한다.
- 수신 기사 위험전가, stale·불안전 후보는 추천하지 않는다.
- 사용자 입력, 합성 기준계획, 공개데이터 문맥의 출처를 구분한다.
- 실제 TMS·기사·GPS·개인정보·고객 발송과 네트워크 쓰기는 없다.
- Kakao Mobility 도로 geometry와 ASOS 관측 문맥은 Safety 수치·추천·실행 가능성을 변경하지 않는다.
- 390×844와 데스크톱에서 키보드·44px 조작·overflow를 통과한다.
- 전체 회귀, clean-start, production build와 공개 배포 smoke를 통과한다.

## 3. 비목표

- 실제 기사·고객·주소·GPS 입력
- 불완전한 공개데이터를 합성 필드와 혼합한 Live Safety 계산
- LLM의 수치 계산·추천·실행 가능성 판정
- 자동 계획 적용·실제 고객 메시지 발송
- 실제 사고확률 또는 현장 효과 주장

## 4. 다음 최종 단계

Scenario Mode 이후 남는 단계는 승인된 실제 TMS/택배사 Adapter, 실제 인증·역할, 가명 기사 계획·위치 입력, 보존·삭제 SLA, 계획 쓰기 보상 트랜잭션, 고객 발송과 현장 Shadow/Pilot 검증이다. 이 연결은 별도 사용자 재승인과 독립 검증 전에는 활성화하지 않는다.
