## 1. 결정사항

2026-08-14 최종 Goal은 고정된 대표 시나리오를 재생하는 Demo 제출 상태가 아니다. SafeRoute AI는 합성 운영자료로 하루 업무를 처음부터 끝까지 수행할 수 있는 배포된 운영 서비스 후보가 되어야 한다.

> 관리자가 최신 합성 근무표·배송 작업표·경로표를 등록하면 시스템이 출처·날짜·참조·누락을 검증해 불변 일일 운영 스냅샷을 만들고, 모든 활성 기사를 같은 평가시각에서 계산해 복수의 안전지원 결정을 생성한다. 각 결정은 원인 설명, 개입 비교, Risk Transfer Guard, 영향 기사 동의, 관리자 승인, 최신 계획 재검증, 경로·순서·ETA 갱신, 고객안내 초안, 내보내기와 감사기록까지 독립적으로 완결된다.

실제 코드·배포·상태 전이·AI API·지도 어댑터가 동작해야 하며, 단일 fixture에 맞춘 화면 전환만으로 완료를 주장하지 않는다.

## 2. 서비스 모드의 의미

`PAID_PILOT_READY_WITH_SYNTHETIC_OPERATIONS`는 다음을 뜻한다.

- 실제 사용자가 개발자 도움 없이 합성 운영일을 생성하고 전체 폐루프를 수행할 수 있다.
- 입력이 바뀌면 검증된 입력 차이에 따라 계산 결과와 지원 큐가 바뀐다.
- 같은 입력·설정·평가시각에는 같은 결과가 나온다.
- 새로고침·재접속 후에도 승인된 운영 스냅샷과 결정 상태를 복구할 수 있다.
- 외부 AI·지도 실패는 핵심 안전 계산과 승인 기록을 손상시키지 않는다.
- 한 운영사와 합성 데이터 기반 Shadow/Paid Pilot을 시작할 수 있는 템플릿·운영절차·내보내기를 제공한다.

이는 실제 개인정보, 실제 GPS, 택배사 비공개 TMS 쓰기, 실제 고객 메시지 발송, 현장 사고감소 효과 또는 법률·노무 승인 완료를 뜻하지 않는다.

## 3. 기준 운영 흐름

1. 관리자가 운영일과 합성 데이터 패키지를 선택하거나 표준 파일을 등록한다.
2. 시스템이 문서 종류, 출처, 기준일, 필수 필드, 상위 레코드와 기사·계획·배송지 참조를 검증한다.
3. 오류와 결측은 자동 보정하지 않고 수정 가능한 검토 결과로 표시한다.
4. 관리자가 검증된 입력을 확정하면 `DailyOperationsSnapshot`을 새 버전으로 고정한다.
5. 시스템이 모든 활성 기사의 Safety Budget·Time-to-Breach·기여요인·신뢰도를 계산한다.
6. 지원이 필요한 모든 기사에 별도 `DecisionRecord`를 만들고 지원 큐에 표시한다.
7. 개입 후보는 동일 스냅샷에서 비교하고, 물량이관은 수신 기사와 다른 열린 결정까지 재검증한다.
8. 영향받는 기사는 같은 decision ID와 근거로 동의·수정 요청·거절한다.
9. 관리자는 승인·보류·수정 요청·취소를 기록한다.
10. 승인 직전 최신 운영 스냅샷과 계획 버전을 재검증한다.
11. 적용은 경로·배송순서·작업량·ETA를 원자적으로 갱신하고 실패하면 기존 계획을 유지한다.
12. 고객안내는 발송하지 않고 적용된 ETA 기반 초안으로 기록한다.
13. 갱신 계획·지원 결과·고객안내 초안·감사 이벤트를 CSV/JSON으로 내보낸다.

기사 응답은 관리자 대리 버튼이 아니라 별도 Field-first 화면에서 기록한다. 기사와 관리자 화면이 동시에 열려 저장 기준시각이 달라지면 오래된 쓰기를 거부하고 최신 상태를 다시 불러온다.

## 4. AI와 외부 서비스 책임

### 결정론적 SafeRoute 코드

- 모든 Safety Budget·Time-to-Breach·신뢰도·결측 판정
- 후보 효과·실행 가능성·Risk Transfer Guard·추천 순위
- 동의·승인·재검증·원자적 적용·감사 상태

### Upstage

- 허용된 합성 문서의 Parse·Extract
- 추출 필드와 원문 인용의 strict 검증
- 검증된 JSON을 기반으로 한 역할별 설명

### A.X

- 검증된 입력만 사용하는 관리자 일일 요약·결정 메모·고객안내 초안
- 숫자·추천·실행 가능성을 변경하지 않는 strict 출력

### K-EXAONE

- 합성 경계·충돌 시나리오 생성과 평가 하네스
- 제품 런타임 결정권 없음

### Kakao

- 합성 위치의 지도와 길찾기 미리보기
- Safety 계산·추천·승인 계획을 변경하지 않음

모든 외부 계층은 `LIVE`, `MOCK`, `FALLBACK`, `ERROR`를 명시하고 실패 시 결정론적 서비스 흐름을 유지한다.

## 5. 필수 완료 Gate

- 합성 운영 레코드 25명을 한 운영일로 불러오고 전원을 평가한다.

- 한 운영일에 복수의 열린 decision을 선택·처리할 수 있다.
- 동일 기사, 수신 기사, 계획 버전 또는 운영 스냅샷 충돌을 적용 전에 차단한다.

- Kakao·AI API가 실패해도 운영 입력·계산·동의·승인·내보내기가 가능하다.
- 표준 입력 템플릿과 갱신 계획·고객안내·감사 내보내기가 있다.
- 관리자 1280×720·1440×900, 기사 360×800·390×844의 핵심 과업을 통과한다.
- 관리자 독립 검토 최소 3명과 기사 독립 검토 최소 5명에서 중대 제품 오인 0건을 확인한다.

- 여섯 심사기준의 모든 주장은 실행 증거와 SHA-256 manifest에 연결된다.

## 10. 일정상 미실시 Gate 처리

2026-08-07 사용자 결정에 따라 관리자 3명·기사 5명의 운영 서비스 독립 검토는 이번 일정에서 수행하지 않는다. 따라서 이 문서의 목표 상태는 달성됐다고 판정하지 않으며, 공개·발표 문구는 `합성 운영 데모 준비 완료 · 독립 사람 검토 미실시`로 제한한다.
