# 카드 선택 표현 가드레일

## 문서 상태

- 상태: Approved
- 담당: 팀 안전빵
- 최종 갱신: 2026-07-31

## 결정사항

- 기사 카드, 안전여유 면, 지원 큐와 선택 카드의 좌우 한쪽에 상태색 띠를 붙이지 않는다.
- `inset box-shadow`로 한쪽 선택선을 만드는 표현도 같은 패턴으로 간주해 금지한다.
- 선택 상태는 사방의 동일한 경계, 옅은 배경색, 명시적 상태어로 표현한다.

## 이유

한쪽 강조선은 사용자에게 카드 옆 그림자처럼 보였다. 같은 패턴을 이름만 바꾸어 재도입하지 않도록 CSS 구현 수단까지 금지 범위에 포함한다.

## 수용기준

- 선택된 지원 큐 항목의 `box-shadow` 계산값은 `none`이다.
- 선택된 지원 큐 항목의 네 방향 경계 폭과 색상이 각각 동일하다.
- 카드 측면 상태선이 없어도 상태어와 수치가 유지된다.

## 비목표

- 키보드 포커스를 위한 사방의 `focus-visible` 외곽선 제거
- 지도 마커의 사방 선택 링 제거
- 상태 배경색이나 명시적 상태어 제거
